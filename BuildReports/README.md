# Build Reports

This directory contains concise, machine-readable evidence generated by Unity
editor tooling.

- `desktop-validation-report.json` records the latest data and rules validation.
- `approved-model-integration.json` records the native glassware prefabs and
  collider results.

Windows build and runtime smoke reports may also be generated here. Commit them
only when they match the current source revision. Raw Unity logs, player builds,
screenshots, and temporary captures are local artifacts and are ignored.
